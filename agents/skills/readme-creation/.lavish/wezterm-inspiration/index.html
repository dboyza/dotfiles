Which tab row you see matters

With one native WezTerm tab open, your config hides its tab bar. Inside tmux, the bottom row is tmux's window list: a solid gray-purple strip with centered names and a cyan active dot.

For a visible everyday change, we should style the row you actually use and keep both layers visually coordinated.

One unusually useful improvement:

Your current width budget truncates native tab names quickly. Readable project names may improve the result more than adding extra icons.

  1. Make the active tab unmistakable. Use one lavender capsule, with dark text and muted inactive tabs.
  2. Let labels breathe. Aim for roughly 18-24 cells when space permits, shrinking gracefully in narrow windows.
  3. Keep the overall palette coordinated. Carry the same background and accent colors through WezTerm, tmux, and Neovim.
  4. Choose one primary navigation row. Style tmux's bottom row if that is your daily tab interface, and match native WezTerm tabs for other sessions.
Implementation notes for a later change

WezTerm offers native-looking tabs with proportional fonts and a retro bar using terminal cells. The retro bar supports the kind of custom labels shown in most of these examples. See the official appearance reference.

These references establish a visual direction, not tested compatibility with your complete configuration. A later implementation should preserve your macOS, Windows, and WSL branches, coordinate with tmux, and verify long labels and narrow windows.
